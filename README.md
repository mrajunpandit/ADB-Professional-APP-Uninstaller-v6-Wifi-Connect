# ADB Professional App Manager v6

A powerful Windows PowerShell WPF GUI tool for Android app management via ADB.

## Features
- WiFi Connect (Wireless Debugging — pair + connect)
- USB + WiFi device support
- Bulk app uninstall (user & system apps)
- Search apps by name or package
- Dark & Light theme
- No installation required — just run the .ps1 file

## Requirements
- Windows PowerShell 5.1
- ADB (Platform Tools) installed at C:\platform-tools\ or in PATH

## Usage
Right-click the .ps1 file → "Run with PowerShell"
